## How to read this

- **Test(s):** `tests/<file>.py :: <test>` is a pytest test (fake model, no network); `measured: <path>` is a committed eval or discovery result; `live: …` is a check on the deployed URL recorded in `docs/ai-log.md`; `manual: …` is a human check.
- **Status:** **Done (tested)** = a test or committed result would fail if the requirement broke. **Done (live check)** = proven on the deployed app (T17/T18), not by CI. **Partial** = built, with what is missing named. **Planned (T21)** = waits for the final 360-call run, README numbers and video. **Gap** = unmet, with the reason.
- Eval numbers come from the held-out 150 calls; the reported numbers are T21's run on all 360 non-dev calls.
