# Scheduling Guide for Agents
_Rev 2024-11_

- Book the earliest available window that matches the customer's request. Offer the waitlist if nothing within 48 hours.
- Members get priority: if a member calls and the next window is more than 24 hours out, check the member-reserved slots (marked RES in the scheduler).
- Cancellations require 48 hours notice to avoid a fee.
- Emergency (no-cool above 85°F indoor, no-heat below 55°F, active leak) can be booked into same-day overflow slots.
- Always confirm: service address, gate code if any, pets, and whether anyone over 18 will be home.
- Technicians do not enter a home without an adult present.
